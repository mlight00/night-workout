# 야간 운동

치닝디핑 25분 야간 루틴을 음성으로 자동 진행하는 개인용 웹앱.

## 주소

**https://mlight00.github.io/night-workout/**

## 쓰는 법

폰 크롬에서 위 주소를 열고 **메뉴 → 홈 화면에 추가**. 이후 아이콘으로 실행한다.

시작 버튼을 누르면 끝까지 손대지 않아도 알아서 진행된다. 음성이 안내한다.
화면 아무 데나 탭하면 현재 단계를 즉시 끝내고 다음으로 넘어간다.

## 루틴

| 구간 | 내용 | 시간 |
|---|---|---|
| 웜업 | 어깨 회전 → 팔목·발목 → 제자리 걷기 → 스쿼트 10회 | 3분 |
| 메인 | 데드행 25초 / 팔굽혀펴기 12회 / 딥스 버티기 20초 / 다리 들고 버티기 20초 (각 3세트) | 약 19분 |
| 쿨다운 | 가슴 → 광배근 → 어깨 후면 스트레칭 | 3분 |

전체 최대 25분 21초. 팔굽혀펴기를 30초쯤에 탭하면 약 24분.

## 개발

빌드 도구가 없다. 파일을 고치면 바로 반영된다.

```bash
# 로컬에서 열기
python -m http.server 8123

# 테스트 (인자 없이. Windows에서 `node --test tests/`는 실패한다)
node --test
```

## 루틴 바꾸기

`js/routine.js` 의 숫자만 고치면 앱 전체가 따라간다. 다른 파일은 건드릴 필요 없다.

## 구조

| 파일 | 하는 일 |
|---|---|
| `js/routine.js` | 운동 프로그램 데이터 |
| `js/timeline.js` | 루틴을 42단계 목록으로 전개 |
| `js/timer.js` | 진행 엔진 (시각 주입식, 순수 로직) |
| `js/coach.js` | 음성 문구 |
| `js/storage.js` | 기록 조립·저장 |
| `js/ui.js` | 화면 갱신 |
| `js/wakelock.js` | 화면 꺼짐 방지 |
| `js/app.js` | 조립 |

`routine`/`timeline`/`format`/`timer`/`coach`/`storage`는 브라우저를 모르는 순수 로직이라
카메라·화면 없이 `node --test`로 전부 검증된다.
