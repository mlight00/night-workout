# 야간 운동

치닝디핑·실내 자전거로 하는 하루 25~30분 주간 루틴을 음성과 3D 자세 모델로 안내하는 개인용 웹앱.

## 주소

**https://mlight00.github.io/night-workout/**

폰 크롬에서 열고 **메뉴 → 홈 화면에 추가**.

## 무엇을 하나

- **월~금은 근력 → 자전거 → 근력 …** 번갈아. 토·일은 선택 — 운동해도 되고 「오늘은 쉬기」로 넘겨도 된다(차례는 그대로 이어진다). 6일 연속이면 휴식을 권한다.
- **근력 날**: 웜업(어깨 돌리기 · 팔목·발목 · 제자리 걷기) → 스쿼트 · 팔굽혀펴기 · 매달리기 · 엉덩이 들기 · 딥스 · 다리 들기, 종목마다 레벨 사다리. 엉덩이 들기는 하체 주 10세트를 채우려고 더함. 자전거는 꺼내지 않는다.
- **팔굽혀펴기**: 세트별 목표 횟수(10·8·6 → 12·10·8 → 15·10·8 …).
- **ACSM 2026 반영** (Currier 외, *Med Sci Sports Exerc* 2026;58(4):851-872): 끝까지 짜내지 않고 2~3개 여유 남기기, 종목당 2~3세트·주 2회 이상, 스쿼트·팔굽혀펴기는 천천히 내리고(2~3초) 힘차게 올리기, 하체를 맨 앞에.
- **자전거 날**: 웜업은 편하게 2분 → 저항을 올리며 3분(심박은 늦게 따라오니 느낌으로). 루틴은 자전거 날마다 **인터벌(세게↔편하게) → 피라미드(저항 올렸다 내리기) → 빠르게 돌리기** 차례, 홈에서 바꾸거나 **꾸준히**를 고를 수 있다. 레벨이 오르면 시간과 세게 하는 시간이 늘어난다. 심박 안내는 135, 한계는 140.
- **벽에 기대 버티기**: 자전거 날 쿨다운 뒤 3세트(30초 → 2분). 혈압을 낮추는 효과가 확인된 버티기 운동. 혈압약 없이 혈압이 높으면 시작 전에 의사와 상의.
- **유산소 주 150분**: 홈에 "이번 주 유산소" 카드 — 자전거 탄 시간은 자동, 걷기는 +10·+20·+30분 버튼으로 기록. 기록·그래프에 주간 합계.
- **잠깐 멈춤**: 운동 화면 위 ⏸ 버튼 — 남은 시간·음성·예약된 비프음이 모두 멈추고, 계속하기를 누르면 멈춘 곳부터 이어 간다.
- **시작 신호는 비프음** `삐·삐·삐·삐이—`. 종목 안내는 휴식 초반에 미리 하고, 끝나기 6초 전부터는 말하지 않는다.
- **운동 평가**: 끝나면 종목마다 실제 횟수·초, 자세(바르게/가끔/많이 흐트러짐), 힘든 정도(여유/적당/한계)를 고른다(기본값은 계획대로). 근력은 "마지막 세트에 몇 개(몇 초) 더 할 수 있었나"로 묻고 2~3개가 딱 좋은 강도. 결과는 여유 있게 성공(바로 레벨업 가능) · 성공 · 유지 · 미달, 지난번 기록과 비교해 보여 준다.
- **레벨업**: 성공 2번(여유 있게 성공은 1번)이면 버튼이 켜진다. 유지는 실패가 아니고, 미달 2번 연속이면 내리기를 권한다. 다음 운동 때 피곤하면 직전 성공은 무효.
- **컨디션 체크**: 피곤하면 가볍게(근력 2세트·자전거 ⅔), 아프면 스트레칭만.
- **3D 자세**: 휴식 중에 다음 동작의 바른 자세가 화면 가득, 운동·자전거 중에는 숫자 위에 작게(동작 설명 한 줄과 함께) 나온다. 「자세 보기」에서 피해야 할 자세, 뼈대 투시, 관절 확대, 실측값. 캐릭터 배는 마지막으로 기록한 체중을 따라간다.
- **자세 포인트 음성**: 3D가 나오는 동안 신경 쓸 자세를 읽어 주고(운동 중엔 10초마다 짧게, 자전거는 90초마다), 그동안 그 부위에 반투명 원을 띄운다. 「자세 보기」의 🔊 설명 듣기는 바른 자세·피해야 할 자세 설명을 차례로 읽는다.
- **체험 모드**: 기록을 남기지 않고 전체 흐름을 빨리감기로 돌려 본다.
- **기록**: 체중(주 1회), 자전거 평균 심박, 근력 레벨 그래프. 기록은 폰 안에만 있고 파일로 내보낼 수 있다.

## 개발

빌드 도구가 없다.

```bash
node tools/serve.mjs 8124      # 로컬 확인 (http://localhost:8124/?speed=30 은 30배 빨리감기)
node --test                    # 테스트 (Windows에서 node --test tests/ 는 실패)
```

- 루틴 숫자: `js/program.js`
- 3D 동작: `js/body3d/poses.js` — 바꾼 뒤 `python tools/shot.py 이름 "deadhang:ok:0.5:62,..."` 로 렌더링해 확인
  (항목 형식 `동작:ok|ng:시점:방향:체중:확대관절:x` — 끝의 `x`는 뼈대 투시)
- 3D 구조: `rig.js`가 보이지 않는 뼈대로 관절을 계산하고, `avatar.js`가 무료 캐릭터의 뼈를 그 방향대로 돌린다
- 앱 화면 캡처: `python tools/appshot.py rest 412 860 30`
